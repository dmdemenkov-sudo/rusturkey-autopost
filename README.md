# Автопостинг gastetv.com → RusTurkey.com

Каждый час с 08:00 до 23:00 (по Стамбулу) скрипт:

1. забирает новые статьи из разделов **Gündem** и **Magazin** на gastetv.com;
2. нейросеть оценивает заголовки: турецкие звёзды, политика «второго ряда», полезное для жизни, резонансные происшествия;
3. лучшие переводит на русский — **не больше 10 в сутки**, равномерно в течение дня;
4. кладёт переводы в RSS-ленту `docs/feed.xml`, которую забирает импорт RSS в админке RusTurkey.

Квоты в сутки: звёзды — 4, политика — 3, полезное — 3, происшествия — 1, прочее — 1.
Меняются в начале `autopost.py` (блок «НАСТРОЙКИ»). Правила отбора и стиль перевода — в `prompts.py`.

## Установка (один раз, ~20 минут)

1. **Ключ Claude API.** console.anthropic.com → Billing → пополнить на $10–20 → API Keys → Create Key. Скопируйте ключ (начинается с `sk-ant-`). Никому его не пересылайте.
2. **GitHub.** Зарегистрируйтесь на github.com → New repository → имя `rusturkey-autopost` → **Public** → Create.
3. Загрузите в репозиторий все файлы из этого архива (Add file → Upload files; папку `.github` тоже — если браузер её не видит, включите показ скрытых файлов).
4. **Секрет.** Settings → Secrets and variables → Actions → New repository secret: имя `ANTHROPIC_API_KEY`, значение — ваш ключ.
5. **Страница с лентой.** Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/docs` → Save.
6. **Первый запуск.** Actions → autopost → Run workflow → в поле указать `3` → Run. Через 2–3 минуты лента появится по адресу
   `https://ВАШ_ЛОГИН.github.io/rusturkey-autopost/feed.xml`.

## Настройка в админке RusTurkey (RSS Feeds → Импорт RSS-канала)

| Поле | Значение |
|---|---|
| Имя канала | gastetv автоперевод |
| URL канала | адрес ленты из шага 6 |
| Количество записей для импорта | 10 |
| Язык | Russian |
| Категория | отдельная, например «Повестка дня» |
| Изображения | **Загрузить изображения на мой сервер** |
| Автоматическое обновление | Да |
| Показать кнопку подробнее | **Нет** |
| Добавить как черновик | **Да** (первые 3–4 недели) |

Если статьи не подтягиваются сами — в Varient автообновление RSS работает через cron-задание на хостинге; его нужно включить у хостера.

## Стоимость

GitHub — бесплатно. Claude API — ориентировочно $5–15 в месяц при 10 статьях в день.

## Если что-то пошло не так

Actions → последний запуск → лог. В нём видно, какие заголовки оценены, что переведено, что пропущено как заглушка («жду дописывания»).
